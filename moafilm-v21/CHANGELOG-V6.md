# 모아필름 v6 — Canva형 애니메이션 타임라인

- 관리자 편집기에 요소별 애니메이션 타임라인 추가
- 효과 시작 지연 및 재생 길이 시각화, 타임라인 요소 선택과 속성 패널 연동
- 전체 요소에 순차 적용하는 3가지 애니메이션 프리셋(차분한 등장/로맨틱/경쾌하게)
- 기존 요소별 효과, JSON 내보내기/가져오기 및 미리보기 유지

주의: 이 기능은 관리자 편집기용입니다. 고객 영상 MP4 렌더링, Supabase 공유, Canva OAuth는 아직 연결되지 않았습니다.
전체 npm 빌드 검증은 패키지 설치 시간 초과로 완료하지 못했습니다.

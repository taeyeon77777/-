# 모아필름 v4 — 템플릿 파일 내보내기/가져오기

## 실제 추가된 기능
- 관리자 템플릿 편집기 왼쪽 하단에서 현재 디자인을 JSON 파일로 다운로드
- JSON 파일을 다시 불러와 현재 선택한 템플릿에 적용
- 파일 형식/크기 기본 검증과 성공·실패 안내
- Canva PNG/JPG 배경 가져오기 및 사진 자동배치는 v3 기능 유지

## 아직 구현되지 않은 기능
- Supabase 서버 저장 및 고객 전체 공유
- 실제 관리자 인증·접근 제어
- 결제 연동 및 상용 MP4 렌더링 보장
- 전체 빌드 및 브라우저 동작 검증

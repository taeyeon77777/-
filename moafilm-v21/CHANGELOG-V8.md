# MoaFilm v8 — 다중 장면 관리자 편집
- 장면 추가, 복제, 삭제, 순서 변경 및 장면 선택
- 장면마다 배경, 텍스트, 사진존, 애니메이션, 길이/전환 설정 별도 보관
- 전체 장면 길이 합계 표시
- 브라우저 localStorage에 장면 목록 저장 (서버 공유 아님)

## 아직 구현되지 않은 기능
- 여러 장면의 연속 미리보기 및 전환 재생
- 장면별 설정을 최종 MP4에 렌더링
- 음악 파일 영구 저장, Supabase 공유, 결제

## 검증
- npm install이 실행 시간 제한으로 종료되어 전체 빌드 검증 미완료
- 기존 v7 운영 환경에 직접 배포하지 않음

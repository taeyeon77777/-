# 모아필름 v14 — 영상 출력 안정성 10항목

1. 사진 최대 300장 제한
2. 빈 사진 주소 입력 검증
3. 사진당 재생 시간 1~30초 범위 및 유한 숫자 검사
4. 음악 파일 크기 제한(기본 50MB), 빈 파일 거부
5. 음악 파일 형식 검사
6. 이미지 로딩 중 작업 취소 지원
7. 영상 생성 시작 시 진행률 0% 표시
8. 프레임 대기 이후 취소 신호 재확인
9. MediaRecorder 종료 지연 시 15초 오류 안내
10. 다운로드 파일명 위험 문자 제거 및 확장자 제한

## 검증
- `tsc --noEmit --target ES2022 --module ESNext --lib DOM,ES2022 src/app/utils/videoExport.ts`: 통과
- ZIP 무결성 검사: 통과
- 전체 Vite 빌드: 미검증 (node_modules 없음)
- 브라우저 실재생 및 MP4/오디오 출력: 미검증
- 운영 사이트 배포: 하지 않음

이 버전은 관리자 레이어를 MP4로 렌더링하는 기능의 완성을 의미하지 않습니다.

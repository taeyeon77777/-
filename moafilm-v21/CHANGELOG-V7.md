# 모아필름 v7 변경사항
- 관리자 템플릿에 장면 길이(2~30초), 장면 전환 유형(컷/페이드/슬라이드/줌), 전환 시간 저장
- 타임라인에 장면 길이와 선택 음악 트랙 표시
- 로컬 음악 파일(MP3/WAV/OGG, 25MB 이하) 선택 및 브라우저 오디오 미리듣기, 볼륨 설정
- 장면 메타데이터는 기존 JSON 내보내기와 localStorage 저장 구조를 따름

## 제약
- 음악 파일 자체는 서버에 업로드되지 않으며 새로고침 후 재선택 필요
- 여러 장면 전환의 실제 플레이백 및 MP4 렌더링 연동은 미구현
- Supabase/인증/결제 미구현
- 의존성 설치 및 전체 빌드 테스트 미실시

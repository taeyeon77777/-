## 주의
- 요청 제한은 **단일 Python 프로세스 메모리 기반**입니다. 다중 서버, 프록시 뒤 실제 IP 처리, 분산 레이트리밋은 별도 설계 필요.
- 재시작한 작업의 **자동 재시도는 구현하지 않았습니다**. 업로드 원본이 재시도 가능하도록 영구 보관되지 않기 때문입니다.
- 로그인 공격 방어는 기본 보완일 뿐이며 보안 감사 완료를 의미하지 않습니다.
- PG 실결제, 실제 서버 배포는 포함하지 않습니다.

# v6 쉬운 설정 업그레이드

- 사진 개수·시작/종료 시간·레이아웃 입력으로 사진 슬롯 일괄 생성
- 슬롯 키 충돌 회피, 균등 시간 분할, 범위 검증
- 신랑/신부 이름 슬롯 원클릭 생성
- 가운데/좌/우/전체/정사각형 배치 프리셋
- 빠른 설정 되돌리기(최대 20회, 현재 편집 세션)
- 기존 관리자 MP4 업로드·렌더링 API 유지

주의: 자동 생성은 캔바 영상의 빈 공간을 AI로 인식하는 기능이 아닙니다. 관리자가 배치 구간을 선택하고 결과를 확인해야 합니다. 프리셋을 적용하면 해당 슬롯의 이동 키프레임은 초기화됩니다.

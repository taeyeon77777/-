# 모아필름 배포 준비 개발판 (상용 공개 전 보안검토 필수)

## 추가 구현
- `MOAFILM_DATA_DIR` 아래 SQLite, 템플릿, 업로드 원본, 렌더 결과, 작업 JSON을 영구 저장할 수 있도록 경로 분리
- 비밀번호 재설정 요청 `/api/password/forgot`, 재설정 `/api/password/reset` (토큰 30분, 1회 사용, 기존 세션 무효화)
- 이메일 인증 토큰 발급(가입 시 SMTP 설정이 있는 경우) 및 `/api/email/verify`
- `MOAFILM_REQUIRE_VERIFIED=1` 설정 시 고객 로그인에 인증 필요 (관리자 예외)
- 완료/실패 렌더 작업 상태 JSON 저장: 재시작 후 조회 가능. **진행 중 작업의 자동 복구/재시도는 미구현**
- Docker 비루트 사용자, Docker Compose 영구 볼륨, 환경변수 샘플

## 로컬 실행
Python 3.12+, Pillow, ffmpeg/ffprobe 필요. `python studio.py` 실행. 기존 `start_windows.bat`도 이용 가능.

## 서버 준비
1. `.env.example`을 `.env`로 복사하고 도메인, SMTP 및 비밀 설정 입력. `.env`를 공개 저장소에 올리지 말 것.
2. `docker compose up --build -d` (Docker가 설치된 Linux 서버). 127.0.0.1:8890에만 연결됨.
3. 운영 도메인에 대한 HTTPS 리버스 프록시(Caddy/Nginx 등)를 **별도 설정**해야 함.
4. `/data` 볼륨 백업 및 복구 테스트, 로그/모니터링, 관리자 초기 계정 부트스트랩 후 환경변수 해제.

## 주의 및 미완료
- **실제 인터넷 서버에 배포하지 않았습니다.** 호스팅 계정/도메인/SMTP 자격 증명 없음.
- SMTP 서버가 없으면 인증·재설정 이메일을 보낼 수 없음. UI에도 인증/재설정 입력 화면은 아직 없음(현재 API만 제공).
- 가입 이메일 발송 실패 시 가입 자체는 DB에 남을 수 있음. 운영용 트랜잭션/재발송 설계 필요.
- 고객 사진 등 민감한 파일의 보관 기간 및 삭제 정책, 파일 격리, 백업 암호화 미완료.
- 작업 자동 재시도/영속 큐 미완료. 서버 재시작 시 진행 중 작업은 복구되지 않음.
- CSRF 토큰, 레이트 리밋, 보안 헤더 검토, 부하 테스트, 악성 파일 방어, 계정 잠금 및 이메일 발송 악용 방어 필요.
- 실제 PG 연동/실결제는 계약 후 가능. 모의 결제는 실제 돈이 이동하지 않음.
- 단일 SQLite/단일 FFmpeg 서버 프로토타입이며, 다중 인스턴스/대규모 상용 서비스로 검증되지 않음.

# v8: 움직이는 마커의 위치 키프레임 자동 생성

- v7의 초록색 마커 인식 기능 유지.
- 시간에 따라 이동하는 검출 영역을 최대 25개 시점에서 샘플링하고, 사진 영역의 x/y 키프레임으로 저장.
- 관리자 화면에 자동 생성된 키프레임 개수를 표시하고 미리보기 확인을 안내.
- 크기 변화, 회전, 겹치는 마커, 빠르게 이동해 프레임 간 겹침이 없는 경우는 정확하게 추적하지 못할 수 있음.
- 영상의 마커는 고정 크기의 채워진 초록색 사각형을 권장. 움직임이 큰 경우 수동 보정 필요.
- 분석은 미리보기이며 관리자가 적용 및 템플릿 저장을 눌러야 영구 반영.

검증: python -m unittest -v test_marker_detector test_motion_detector (4 tests passed).
실제 캔바 MP4 및 최종 FFmpeg 렌더링 검증은 수행하지 않음.

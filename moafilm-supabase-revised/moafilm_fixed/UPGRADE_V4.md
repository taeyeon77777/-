# 모아필름 템플릿 편집기 v4

기존 v3의 서버·인증·모의결제·렌더링 기능을 유지하며 관리자/고객 편집 UI를 개선했습니다.

## 추가된 기능
- 영상 재생 위치 슬라이더 및 현재 시간에 활성화되는 레이어만 표시
- 사진 영역 우하단 핸들로 가로·세로 크기 드래그 변경
- 사진·텍스트 영역 복제 및 중복되지 않는 식별자 자동 부여
- 고객 사진 일괄 업로드 후 썸네일 표시
- 업로드된 사진을 편집기 레이어에도 표시하여 배치 확인

## 사용
1. `start_windows.bat` 실행 (Python, Pillow, FFmpeg 필요).
2. 관리자 로그인 후 캔바 배경 MP4 업로드.
3. `+ 사진 영역`을 눌러 시간·위치·크기 설정, 필요하면 복제.
4. `템플릿 저장`, 고객 사진 업로드 후 모의결제, 영상 생성.

## 검증 및 한계
- HTML 인라인 JavaScript 구문 검사 수행.
- 실제 브라우저 E2E 및 영상 전체 렌더링 재검증은 이 변경판에서 수행하지 않음.
- 움직이는 사진 영역의 키프레임·마스킹은 미구현.
- 이 버전은 상용 공개 배포용이 아닙니다.

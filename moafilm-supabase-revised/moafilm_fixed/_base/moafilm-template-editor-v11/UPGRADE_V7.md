# v7 색상 마커 자동 인식

1. 캔바에서 실제 배경 MP4를 내보내 등록합니다.
2. 동일한 타임라인의 복제 디자인에서 사진 영역을 **순수 #00FF00 단색 사각형**으로 채워 인식용 MP4를 내보냅니다. 사진 영역 외에는 이 색을 사용하지 마세요.
3. 관리자 → 사진 자리 자동 인식 → 인식용 MP4 업로드 → 분석 → 후보 확인 → 적용 → 템플릿 저장.

검출: OpenCV HSV 초록색 임계값, 연결 요소 면적·채움 비율 필터, 시간축 IoU 추적, 짧은 노이즈 제거. 인식용 파일은 분석 후 삭제. 인식 결과는 승인 전에는 저장하지 않음. 움직이는 마커는 경고만 제공하며 키프레임은 자동 생성하지 않음. 색상/압축/화면 전환에 따라 오검출 및 미검출 가능. 실제 배경과 가이드 영상의 길이 차이는 0.25초 이하만 허용. 최대 25MB, 최대 180초, 최대 360프레임 분석.

로컬 실행: `pip install Pillow opencv-python-headless numpy` 및 FFmpeg 설치. Dockerfile에 의존성 포함.

캔바 배경 MP4 → 사진·글자 영역 지정 → 고객 정보 합성 → Full HD MP4 생성

① 캔바 배경 MP4 등록

16:9, 1~180초, 25MB 이하. 배경에는 교체할 사진·이름을 넣지 마세요.

② 사진 자리 자동 인식 · 초록색 가이드 영상

캔바에서 사진 자리를 순수 초록색 #00FF00 사각형으로 채운 인식용 MP4를 별도로 내보내세요. 실제 배경 MP4와 길이·화면 크기가 같아야 합니다. 초록색 표시가 없는 실제 배경 MP4는 위에서 먼저 등록합니다.

자동 템플릿 제작

초록 #00FF00: 사진 · 자홍 #FF00FF: 이름 · 하늘 #00CFFF: 날짜. 캔바에서 같은 디자인을 가이드 표시 있음/없음으로 각각 내보내세요.

인식 결과는 저장 전 수정할 수 있습니다. 가이드 MP4는 완성 영상에 사용되지 않습니다.

선택한 사진·글자 영역의 고객 안내

고객 업로드 화면에서만 보입니다. 완성 영상에는 합성되지 않습니다.

결과를 확인한 뒤 적용하고, 최종적으로 아래의 '템플릿 저장'을 눌러야 합니다. 움직이는 영역은 위치 키프레임을 자동 생성합니다. 반드시 미리보기를 확인하세요.

② 쉬운 템플릿 설정 · 3분 시작

사진 개수와 구간만 입력하면 사진 영역을 자동 생성합니다. 기존 영역은 삭제하지 않고 추가됩니다.

영상을 확인하면서 필요한 영역만 드래그해 조절하고 저장하세요.

② 사진·이름 영역 편집

영상을 재생하거나 원하는 시간으로 이동한 뒤 영역을 추가하세요. 분홍색 영역은 드래그해 이동할 수 있습니다. 시간·크기·위치는 아래 입력칸에서 조절합니다.

선택 영역 빠른 설정

배치 버튼은 선택 영역의 크기·위치를 변경합니다. 되돌리기는 자동 생성과 빠른 배치에 적용됩니다.

현재 시간에 표시되는 사진·글자 영역만 화면에 보입니다. 노란색 모서리를 드래그하면 크기를 바꿀 수 있습니다.

사진 이동 키프레임

영상을 원하는 시점으로 이동 → 사진을 드래그하여 위치 조정 → 현재 위치를 키프레임으로 저장. 두 시점 사이에서 사진이 부드럽게 이동합니다. 현재는 위치 이동만 지원합니다.

③ 관리자 편집 도우미 · 최종 점검

사진 영역을 선택해 해당 장면으로 이동하고, 잘못된 설정을 저장 전에 확인하세요.

단축키: Alt+←/→ 시간 이동, Alt+S 저장. JSON 백업에는 배경 MP4가 포함되지 않습니다.

②-1 여러 MP4 장면 연결

장면 MP4를 순서대로 등록합니다. 전환은 컷 또는 0.5초 페이드입니다. 장면 길이의 합계에서 전환 중복 시간을 뺀 값이 최종 길이입니다. 사진·글자 표시 시간은 전체 영상 기준으로 지정합니다.

③ 배경음악 설정

별도 음원을 등록하지 않으면 캔바 MP4에 포함된 소리를 유지합니다. 별도 음원을 등록하면 해당 음악으로 교체합니다.

④ 고객용 사진 자동 배치 및 최종 영상

결제 전

사진을 한 번에 선택하면 사진 영역의 시작 시간 순서대로 자동 배치됩니다. 각 사진은 개별 교체할 수 있습니다.

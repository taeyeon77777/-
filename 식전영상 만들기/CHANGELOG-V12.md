# v12 — 영상 내보내기 기능 개선

1. 장면 전환 컷/페이드/슬라이드/확대 효과를 브라우저 캔버스 렌더링에 연결.
2. 영상 출력 화면에서 장면당 재생 시간 조절.
3. 사용자 선택 MP3/WAV 오디오를 Web Audio API로 녹화 스트림에 포함.
4. 출력 UI에 실제 음악 포함 여부 표시(기존 fixedBgm 명칭만으로 포함됐다는 오해 방지).
5. MP4 미지원 브라우저에서 WebM 형식으로 출력하고 실제 확장자 유지.

검증: TypeScript 트랜스파일 문법 검사 및 코드 경로 정적 점검. 브라우저 런타임/전체 Vite 빌드는 미검증. 이 내보내기는 아직 관리자 편집기의 전체 요소/타임라인을 동일하게 재현하는 엔진이 아니며 고객 사진 슬라이드 기반임.

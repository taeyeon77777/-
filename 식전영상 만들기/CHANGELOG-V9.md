# 모아필름 v9 — 전체 장면 연속 재생

- 관리자 편집기 상단에 `▶ 전체 장면 재생` 버튼 추가
- 장면별 설정된 duration(초)에 따라 자동으로 다음 장면으로 이동
- 현재 장면 번호, 경과 시간 및 진행률 표시
- 전체 재생 중지 및 기존 요소 애니메이션 미리보기 유지

## 현재 한계
- 장면 전환의 페이드/슬라이드/줌 효과는 아직 재생 엔진에 반영되지 않음
- 음악은 장면 연속 재생과 자동 동기화되지 않음
- MP4 내보내기, 서버 저장, 고객 공개 기능은 미완성
- npm 의존성 설치 및 브라우저 통합 테스트는 미실시

# MoaFilm v19 — 고객 입력 테스트 저장/복원

- 고객 테스트 입력값 JSON 다운로드
- 고객 테스트 입력값 JSON 가져오기 및 템플릿 ID 검사
- 고객 테스트 입력 초기화
- 사진 URL·텍스트 값 유효성 검사
- 입력된 고객 데이터로 장면 모델 생성하는 순수 함수
- 원본 템플릿 불변성 유지
- 사진 입력 수 집계
- JSON 직렬화/파싱 오류 처리
- 테스트 파일 크기 제한(15MB)
- 입력 파일에 개인 사진 포함 가능 경고

## 검증
- 고객 데이터 엔진 TypeScript 컴파일 통과
- 단위 테스트 9개 단언 통과
- 전체 Vite 빌드, 브라우저, MP4 미검증
- 관리자 화면에만 연결, 고객 공개 및 Supabase 미연동
